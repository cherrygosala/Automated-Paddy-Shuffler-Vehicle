# Automated Paddy Shuffler Vehicle (APSV)

## Overview
APSV is a Cyber-Physical System for agricultural automation.
This repository combines:
- Embedded control (Arduino)
- Computer vision (OpenCV)
- Decision logic (CPS)

## Project Structure
- embedded/ : Microcontroller (Arduino) code
- vision/   : OpenCV camera and image processing
- cps/      : Decision-making logic
